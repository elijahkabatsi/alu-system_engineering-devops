# Web Stack Debugging #1

## Description
This project is part of the Web Stack Debugging series. The goal is to get Nginx running and listening on port 80 of all the server's active IPv4 IPs.

## Problem
Nginx was installed but not running, causing a connection refused error on port 80.

## Fix
Start Nginx using the service command.

## Usage
```bash
./0-nginx_likes_port_80
```
